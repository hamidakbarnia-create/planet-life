## 8. Rollback procedure (retain)

To roll back production to the static conversation provider:

1. In Railway Variables, set `CONVERSATION_GENERATION_PROVIDER=static`.
2. Optionally remove or leave unused `OPENAI_API_KEY` / `OPENAI_MODEL` / `OPENAI_TIMEOUT_SECONDS` (static mode does not require them).
3. Redeploy or restart the service so lifespan startup validation runs.
4. Confirm health: `GET /` → healthy.
5. Smoke: `POST /api/v1/conversation/execute` with the minimal payload in §3.
6. Confirm response uses the static surface copy (or otherwise expected static behaviour) and that the public schema remains unchanged.
