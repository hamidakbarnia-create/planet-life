## 10. Risks

1. AR language retry dependence — intermittent English-dominant provider output could degrade to fallback if retry fails.
2. DNS gap — sharing workers.dev URL is fine for internal staging; external testers need the documented Railway/CF hosts until custom DNS exists.
3. Provider latency (~8–14 s Ask end-to-end) is acceptable for staging readiness but needs monitoring before production SLOs.
